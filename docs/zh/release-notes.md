# 版本说明

[English](../en/release-notes.md)

## v0.1.10

这是一次专注于 Pixiv 标签抓取的小版本更新。安装版可以直接覆盖升级，`artists.json`、图库索引、相似图片结果、隔离记录和设置都会继续保留。

### 标签抓取改为增量

- 抓取过的作品不再重复抓取。标签记录改存到 `.pixiv-pbd-manager/pixiv_tags.json`，按作品 ID 保存；抓取成功的结果会一直沿用，无需重抓。
- 首次升级会自动沿用图库索引里已有的标签，不会因为换了存储方式而全部重来。
- 工具栏保留原来的“抓取 Pixiv 标签”（只抓没抓过的），新增“重新抓取标签”用于忽略缓存强制重抓；详情页里的单张按钮始终强制重抓。
- 抓取失败的作品下次运行会自动重试；连续失败三次后改为每周重试一次，避免已删除或已设为私密的作品拖慢之后的每一次抓取。
- 整个列表都已缓存时会提示“标签均为最新”，不再看起来像按钮没有反应。

### 修复

- 整理或改名后不再丢失已抓取的标签。此前标签按文件路径保存，而相似图片清理会移动文件，导致下一次扫描把标签清空并被迫全部重抓。
- 抓取过程中每 25 个作品保存一次进度，中途取消或意外退出不会丢掉已经完成的部分。
- 写入 JSON 改为先写临时文件再原子替换。此前写到一半退出会留下截断的文件，而读取端会把解析失败当成空文件，等同于静默丢失整个索引。
- 长时间抓取标签期间对图片做的评分、收藏和标签修改不会再被覆盖回旧值。
- 更新前端构建依赖，修复 npm 审计报告中的安全问题；审计结果现为 0 个漏洞。

### 升级说明

- 推荐退出旧版本后再安装 `Pixiv.PBD.Manager_0.1.10_x64-setup.exe`。
- 用户数据默认仍位于 `%APPDATA%\PixivPbdManager\.pixiv-pbd-manager\`。
- 本版本新增 `pixiv_tags.json`；降级回旧版本仍可正常使用，旧版本会忽略该文件。

完整代码变化：[v0.1.9...v0.1.10](https://github.com/J-FPV/Pixiv-PBD-Manager/compare/v0.1.9...v0.1.10)

## v0.1.9

这是一次以“素材管理”和大图库交互为重点的更新。安装版可以直接覆盖升级，`artists.json`、图库索引、相似图片结果、隔离记录和设置都会继续保留。

### 图库整理

- 图片支持收藏、0–5 星评分，以及“参考价值高 / 已用过 / 待整理”状态。
- 支持本地图片标签、将已有 Pixiv 标签复制为本地标签，以及多选后的批量编辑。
- CSV 导出会导出所选图片；没有选择时导出当前筛选结果。
- 新增图库体检，检查数据库、失效/重叠路径、危险浏览器目录、隔离目录和索引状态，不会修改文件。
- 索引过期或目录变化时可以后台增量更新，不阻塞艺术家和相似图片操作。

### 预览与相似图片

- 图库详情和相似图片预览会先完整显示长图、竖图，再支持滚轮缩放和拖动平移。
- 图库翻页按钮移到图片两侧，详情浏览更直接。
- 相似结果、隔离任务和任务内文件加入分页，降低大量记录同时渲染的开销。
- 隔离区继续保持“先移动、可恢复、永久删除需二次确认”的安全策略。

### 扫描、识别与任务控制

- 扫描可以取消，关闭扫描预览后可以从“扫描结果”再次打开。
- 扫描预览里的艺术家可以直接打开 Pixiv 页面，方便确认识别是否正确。
- 在线解析会从较新、中间和较旧位置抽取多个作品 ID，单个失效作品不会让整个文件夹识别失败。
- 改进本地文件处理、下载任务进度和资源管理器定位行为。

### 性能与稳定性

- 大图库的标签切换、筛选和侧栏计数改为延后重算，减少明显卡顿。
- 收藏、评分和整理状态在点击后立即反馈，后台按顺序写入，避免连续点击互相覆盖。
- 修复批量标签窗口中复选框错位的问题。
- stdin JSON 统一按 UTF-8 处理，并兼容 Windows PowerShell 5.1 写入的 UTF-8 BOM。

### 升级说明

- 推荐退出旧版本后再安装 `Pixiv.PBD.Manager_0.1.9_x64-setup.exe`。
- 用户数据默认仍位于 `%APPDATA%\PixivPbdManager\.pixiv-pbd-manager\`。
- 本版本不会主动删除图库文件；相似图片清理仍只会把确认的文件移入用户指定的图库外隔离目录。

完整代码变化：[v0.1.8...v0.1.9](https://github.com/J-FPV/Pixiv-PBD-Manager/compare/v0.1.8...v0.1.9)
