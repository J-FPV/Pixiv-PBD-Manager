# 备份与安全撤销（开发版）

[English](../en/backup-recovery.md)

此功能尚未发布。入口为“设置 → 备份与恢复”；艺术家与图库的“更多”菜单也提供撤销，标注保存后会显示短暂的快捷撤销提示。

## 自动备份

- 默认位于当前应用数据目录的 `.pixiv-pbd-manager/backups/`，操作历史位于同目录的 `recovery.sqlite3`。自定义数据库、索引路径按数据集隔离历史。
- 每日首次写入前，内容有变化才保留日常备份，最多 14 份。批量修改、扫描应用、艺术家删除、作者标签定义修改、作品索引重建及设置重置前创建恢复点，最多 20 份。
- “立即备份”创建的手动备份和导入的备份不自动清理；可手动导出 ZIP 到其他磁盘。仅本机备份不能防止硬盘损坏。
- 备份包含艺术家数据库、图片标注、设置及持久化界面偏好，以及独立的“合集”类别。不会包含原图、缩略图、Cookie、授权状态、浏览器用户数据或临时筛选缓存。
- 日常备份失败会显示警告。操作前恢复点失败会阻止相应高风险修改，不会删掉旧备份腾出空间。

## 恢复

点击一份备份的恢复图标，选择类别，检查变化数量、明细和失效路径，再确认恢复。每类最多展示 50 条差异明细；数量统计涵盖完整类别。当前状态会先生成恢复点。

选中类别回到备份时点，不合并保留该类别的后续整理修改。未选类别不变。图片标注使用稳定身份关联，只恢复收藏、评分、标签和标记，不回退文件路径、指纹或隔离状态。备份之后新增图片的标注会清空，但图片不会被删除。

导入其他存储的备份时，只自动关联内容校验一致且唯一的图片；重复副本、缺失文件和未验证内容进入“待恢复标注”。恢复不会移动、恢复或永久删除原图，也不能撤回已经执行的隔离区永久删除。

数据存储位置不会被备份覆盖。导入备份保留本机浏览器程序、Python 命令和浏览器数据目录，其他路径的失效项会在预览中列出。备份包含本地路径和整理信息，分享前注意隐私。

恢复时须等待当前任务、标注写入和设置保存结束；准备阶段可以取消。提交开始后会完成或回滚，不会中途杀死后端。恢复完成后重新加载界面，不自动联网识别或下载；开启目录同步时会重新核对本地元数据。

合集恢复只还原规则和成员关系，保留文件当前身份、位置及隔离状态。其他存储的成员仅按唯一且验证一致的内容关联，歧义项保留为待匹配。删除合集不会删除原图。

## 撤销

- 支持图片标签、收藏、评分、标记，以及手动指定文件夹作者、修改作者 ID、修改保存路径和合集编辑。
- 最近 20 个成功操作按顺序逐次撤销，批量操作算一次，重启保留；无变化和失败操作不占名额。第一版不支持重做。
- 后续无关字段的修改会保留；本次操作涉及的内容若已被改动，则整次拒绝撤销，不进行部分恢复。可以确认放弃该条撤销记录，再处理更早的记录。
- 扫描应用、删除艺术家和修改作者标签定义通过备份恢复，历史中标为“仅支持备份恢复”。恢复备份使所选类别的旧撤销记录失效。
- 重置设置、重置窗口布局和重建索引不会删除备份或操作历史。

## 兼容与安全

新备份包格式为版本 2，新增合集 SQLite；继续读取版本 1（不含合集）。含清单和 SHA-256 校验；最多 64 个白名单文件、解压总量最多 1 GiB。未知版本、目录穿越、链接、异常压缩和含触发器的 SQLite 包会被拒绝。

SQLite 采用一致性备份，不直接复制打开的数据库。恢复中断后，下次启动先处理提交日志。损坏的艺术家 JSON 不允许继续覆盖保存；恢复时保留损坏原件的原始内容。

不要同时用旧版和新版软件修改同一个数据目录，旧版不参与新的提交锁与恢复协议。手动复制完整数据目录前应退出软件；不要把 `recovery.sqlite3` 或图片标注 SQLite 当作可删除的缓存。
